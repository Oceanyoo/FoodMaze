[操作示範影片](https://www.youtube.com/watch?v=k97PDFbfRPI&t=3s)

我們設計了一款彰化美食探索迷宮遊戲，將彰化市區的寶藏小吃店隨機藏在迷宮中，玩家在探索迷宮的過程中，可以使用鍵盤方向鍵或手機方向按鈕控制角色移動，並結合計分、倒數計時100秒與終點統整等遊戲機制，增加遊戲的挑戰性。若走到美食點 (隨機散佈在迷宮的角落)，就會解鎖店家的介紹海報，除了提供餐廳資訊與星級評等，也能透過 QR Code 觀看 AI 角色互動影片，及連結至 Google Maps 查看店家資訊。

當玩家成功抵達終點後，系統會將本次遊戲過程中遇到的所有美食點進行成果統整，集中呈現在最終頁面，方便玩家慢慢比較與挑選。

生成式AI應用 

1. ChatGPT｜靈感發想、文案生成、程式開發協作

2. GET-QR | QRcode生成。

3. Playground｜AI圖片生成。

4. recraft｜圖片生成。

5. Pika｜將AI圖片生成動畫。

6. TTSMAKER｜動畫配音。

7. VEED.IO｜動畫剪輯。
